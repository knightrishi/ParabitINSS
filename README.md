# Intelligent Navigation and Sentinel System (INSS)

**INSS** is a hybrid **crowd, vehicle, and parking management platform** designed for large-scale public gatherings such as religious festivals, concerts, sports events, and city-wide celebrations. The system combines traditional security infrastructure with intelligent technologies to enable **real-time monitoring, navigation, access control, and parking management** at scale.

The platform is built around an **Adaptive Hybrid Crowd Management Architecture**, where multiple independent subsystems work together to ensure uninterrupted operations. QR-based identity verification, vehicle registration, parking allocation, wireless occupancy estimation (RSSI/Wi-Fi), and manual security checkpoints collectively provide a resilient event management solution.

A key design principle of INSS is **fault tolerance**. If one subsystem becomes unavailable—such as network connectivity, QR scanners, or wireless sensors—the remaining components continue operating without disrupting the overall event workflow, ensuring reliable crowd management even during infrastructure failures.

### Key Highlights

* **Hybrid Crowd Management:** Combines manual checkpoints with intelligent digital verification.
* **QR-Based Access Control:** Fast attendee and vehicle verification using unique QR codes.
* **Vehicle & Parking Management:** Registration and allocation for personal and commercial vehicles.
* **Real-Time Occupancy Monitoring:** Estimates crowd density using wireless RSSI/Wi-Fi signals.
* **Fault-Tolerant Architecture:** Continues operating even if individual subsystems fail.
* **Scalable Design:** Suitable for events involving thousands to millions of participants.

> **Use Case:** INSS was designed with large-scale event scenarios like the **Maha Kumbh** in mind, where resilient crowd monitoring, navigation, and emergency response are critical.
