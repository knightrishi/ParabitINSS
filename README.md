# ParabitINSS
### Intelligent Navigation and Sentinel System (INSS)
is a hybrid crowd, vehicle, and parking management platform designed for large-scale public events. It combines traditional security practices with intelligent technologies to provide resilient, real-time crowd monitoring and navigation while remaining operational even if parts of the digital infrastructure fail. 
INSS is built on an Adaptive Hybrid Crowd Management Architecture, where manual checkpoints, QR verification and wireless occupancy estimation operate together. The architecture is designed so that the failure of any single subsystem does not compromise the overall operation.
